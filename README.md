# Reg_Categ_Updates

## Roles de usuario

La primera cuenta registrada en una instalación nueva, o el usuario más antiguo de una base de datos existente, se inicializa como **Administrador general**. Este rol puede asignar a las demás cuentas los roles **Administrador**, **Operador** o **Consulta** desde la sección “Usuarios y roles”.

Administrador general, Administrador y Operador pueden crear pautas y registrar modificaciones. Consulta puede acceder a la información, pero no puede escribir ni eliminar datos. Los permisos se validan en el servidor; ocultar las acciones en la interfaz no es el único control.

Las cuentas posteriores al Administrador general se registran inicialmente con el rol Consulta.
